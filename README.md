# Игра Альпинист

По сути - прототип игровой механики по мотивам Donkey Kong Jungle Climber

## Быстрый старт

### Скрипты проекта

```bash
# Установка зависимостей
npm install

# Запуск dev сервера
npm run start

# Деплой на gh-pages
npm run deploy
```

## Управление в игре

Серые квадраты - препятствия, на них можно встать, как на пол.
Зелёные круги - ручки, за которые можно хвататься в полёте и изменять направление движения.

Любые парные кнопки (shift, alt, ctrl, стрелки): зажать левую - движение влево, праву - вправо, зажать обе и одновременно отпустить - прыжок вверх, в полёте - схватится левой или правой рукой за зелёную ручку
На мобильном устройстве, соответсвенно тап и удержание по левой или правой части экрана.
